# مسار (Masar) — من سؤالك إلى وجهتك

مساعد خرائط ذكي بالعربية: تسأل بالكتابة أو بالصوت، فيحلّل لك الأماكن والمسافات القريبة منك ويعرض الجواب على الخريطة.

> مشروع شخصي لإبراز مهارات نظم المعلومات الجغرافية (GIS) والذكاء الاصطناعي.

## ماذا يفعل؟
- **أسئلة بالعربية عن الأماكن القريبة:** مستشفيات، صيدليات، مساجد، مدارس، بنوك، حدائق، وغيرها.
- **رحلة بر آمنة:** يحدد الطريق بين مدينتين، ويقترح محطات الوقود والمستشفيات على الطريق، وينبّه من المسافات الطويلة بلا خدمات.
- **مقارنة وتصدير:** مقارنة بين أماكن، وتصدير النتائج بصيغتي GeoJSON وKML.
- **طقس ومواقيت صلاة واتجاه القبلة** بحسب موقعك.
- **بحث صوتي**، وواجهة تناسب الجوال، ومظهر فاتح/داكن.

## كيف يعمل؟
1. تُكتب الأسئلة بلغة طبيعية.
2. نموذج Claude يختار الأداة المناسبة (tool use) ويحوّل السؤال إلى استعلام مكاني.
3. GeoPandas ينفّذ التحليل المكاني على بيانات OpenStreetMap المحفوظة محلياً (data/city.gpkg).
4. تُعرض النتائج على خريطة Leaflet عبر مكوّن Streamlit مخصص.

## التقنيات
Python · Streamlit · GeoPandas · Shapely · Folium/Leaflet · Claude API (tool use) · OSRM · OpenStreetMap

## التشغيل محلياً
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
أنشئ ملف .env فيه مفتاحك (ولا ترفعه إلى GitHub):
```
ANTHROPIC_API_KEY=your_key_here
```
ثم:
```bash
streamlit run app.py
```
لتحديث البيانات: python fetch_osm.py للطبقات، وpython fetch_places.py لأسماء المدن والقرى.

## حدود الاستخدام
لحماية التكلفة يوجد حد لعدد الأسئلة لكل جلسة وحد يومي للتطبيق، ويمكن تعديلهما بالمتغيرين MASAR_MAX_PER_SESSION وMASAR_MAX_PER_DAY.

## تنبيهات مهمة
- **اكتمال البيانات:** مصدر البيانات OpenStreetMap وهو مبني على مساهمات المتطوعين، فقد تكون بعض الأماكن ناقصة أو بدون اسم. لا يعتمد عليه كمرجع رسمي.
- **المسارات والأوقات تقريبية** وقد تختلف عن الواقع (الازدحام، الإغلاقات، حالة الطريق). لا تعتمد عليها وحدها في رحلات البر.
- **ليس بديلاً عن الطوارئ:** في الحالات الطارئة اتصل برقم الطوارئ (911 / 997).

## الخصوصية
التطبيق لا يحفظ بياناتك على خادم خاص به. لكن لتعمل بعض الميزات تُرسل بيانات إلى خدمات خارجية:

| الخدمة | الغرض | ما يُرسل |
|---|---|---|
| Claude API (Anthropic) | فهم الأسئلة وصياغة الإجابات | نص السؤال وسياق النتائج |
| OSRM | حساب المسارات | إحداثيات نقطتي المسار |
| Open-Meteo | الطقس والبحث عن المدن | إحداثيات الموقع أو اسم المدينة |
| Aladhan | مواقيت الصلاة | إحداثيات الموقع |
| OpenStreetMap Nominatim | البحث عن أسماء المدن (احتياطي) | اسم المدينة |
| بلاط الخرائط ومكتبات CDN | عرض الخريطة والخطوط | عنوان IP وطلبات التحميل |
| خدمة التعرف على الصوت في المتصفح (Google في كروم) | البحث الصوتي | التسجيل الصوتي |

الموقع الجغرافي يُقرأ من متصفحك بعد موافقتك، ولا يُخزَّن.
